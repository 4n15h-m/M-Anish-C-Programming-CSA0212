# Student Attendance and Performance Analysis System (C)

C programming assignment 2 (CO2): control structures and one-dimensional arrays.

## Files
| File | Description |
|------|-------------|
| `01_nested_if.c` | Nested-if eligibility check |
| `02_menu_switch.c` | Menu-driven interface with switch-case and do-while |
| `03_for_loop_marks.c` | Total, average, highest and lowest of 5 marks using for loops |
| `04_while_count_validation.c` | Student count validation using while |
| `05_do_while_menu.c` | do-while menu |
| `06_sentinel_input.c` | Sentinel-controlled input (-1 to stop) |
| `07_nested_loop.c` | Nested loop star pattern |
| `08_continue_demo.c` | Skipping invalid records with `continue` |
| `09_break_demo.c` | Linear search with `break` |
| `10_array_read.c` | Reading values into an array |
| `student.c` | Complete program: records, eligibility, statistics, search, merit list (bubble sort) |

## Compile and run
```
gcc -std=c11 -Wall -Wextra -pedantic student.c -o student
./student
```
